### Copy
Live server integration of a pastebin that supports, TXT and IMG input. It uses a DigitalOcean's Droplet as a server and No-Ip for the DDNS.

If you randomly stumble to this project, well done!!! You can use it freely so long you don't spam the system or use this as a image file storage XD it's just a simple copy paste bin when I find myself needing to copy paste a thing on one device into another lmaoooo
